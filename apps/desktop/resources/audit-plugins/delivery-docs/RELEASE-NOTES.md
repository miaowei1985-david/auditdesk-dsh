# AuditDesk 发布说明（v0.2.2-rc.5）

> 本文档对应内置插件与服务端 0.9.0 系列；每次发布更新「产物与校验」章节。

## 一、审计业务

- 项目全生命周期：建项（含直接上传底表）→ 资料清单（PBC）→ 审计程序 → 底稿 → 报告 → 审批 → 归档 → 归档校验。
- 重要性三级：整体 / 执行 / 明显微小错报临界值。
- 审计程序模板：年报 / 专项 / 内控三类，自动生成程序表（Word / Excel）。
- 底稿 14 类：货币资金、应收账款、存货、营业收入成本、试算平衡、期后事项、持续经营、关联方、或有事项、期初余额、会计政策与估计、风险评估、固定资产、应付职工薪酬、应交税费。
- 底稿归档包：README + 底稿清单 + SHA256 校验值；支持上传 ZIP 一键校验，失败自动告警并生成复核审批。
- 报告：检查清单 / 审计意见 / 报告初稿 / PDF；版本状态（草稿、复核中、已复核、已定稿）；报告复核审批通过后自动标记已复核与复核人。
- 项目归档：只读保护 + 归档包校验（SHA256 清单 + 校验值 CSV）。

## 二、工作台与协同

- 项目看板：PBC、底稿、程序、审批进度一目了然。
- 我的待办：指派审批、超期徽标（>7 天红色）、只看超期、点击直达相关分区。
- 操作留痕：全量留痕、项目/类型/操作人/日期筛选（记忆）、分页、按页导出、全量导出（带筛选摘要与数据来源版本）。
- 最近访问 / 已固定项目：快速切换、显示项目状态与待审批角标、角标直达审批。
- 知识库：准则/法规检索，回答可标注出处。
- 用户与权限：管理员 / 合伙人 / 经理 / 审计员 / 只读；归档项目只读；越权 403。

## 三、运维与安全

- 自动备份：按间隔备份、保留份数、校验、删除、按天清理。
- 恢复：完整性门禁 + 恢复前自动安全备份。
- 恢复演练：一键创建/校验副本并留痕，health 显示最近演练，支持记录查看与 CSV 导出。
- 审批超期自动扫描：可配置天数/间隔/去重；手动立即扫描；超期升级提醒与审批联动。
- 运维报告：Markdown / PDF 导出，Webhook 推送（失败重试、告警留痕），可配置每日定时推送。
- 系统状态：后台任务总览（超期扫描/报告推送/自动备份）、系统操作统计与明细、磁盘/生成目录/上传目录占用。
- 安全：登录会话、角色校验、操作留痕、数据来源版本写入所有导出物。

## 四、客户端

- Windows / macOS 桌面端（内置审计插件，离线安装包）。
- 内网部署：网关与工作台运行在事务所服务器，审计人员 PC 通过浏览器或客户端访问。
- 自动更新默认关闭（未签名场景安全策略）。
