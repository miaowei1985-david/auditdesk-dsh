# AuditDesk 审计工作台 用户培训手册（V1.0）

> 适用：事务所合伙人、项目经理、审计员、IT 管理员
> 环境：Windows 10/11 客户端或内网浏览器访问工作台

## 1. 登录与角色

1. 打开 AuditDesk → 点击左侧「客户与项目」→ 输入账号密码。
2. 角色说明：
   - 合伙人/管理员：审批、归档、用户与系统设置；
   - 项目经理：审批、成员管理、报告复核；
   - 审计员：项目执行、底稿、报告初稿；
   - 只读：查看与导出。

## 2. 每日工作流（审计员）

1. **进入项目**：左侧「最近访问」或客户列表选择项目。
2. **资料清单（PBC）**：上传客户提供的底表，状态切换「已交/待补」。
3. **审计程序**：勾选执行情况，程序表可导出 Word/Excel。
4. **底稿**：一键生成 11 类底稿 → 台账切换状态 → 可导出底稿台账 CSV。
5. **报告**：生成检查清单/意见/初稿 → 提交复核。
6. **操作留痕**：所有关键动作自动记录，可筛选导出。

## 3. 项目建项与导入

1. 「+ 新建项目」→ 填写客户、项目名称、期间、业务类型（年报/专项/内控）。
2. 可从建项弹窗直接上传试算平衡/序时账/财务报表；也可在项目内「资料清单」导入。
3. 导入失败会给出字段缺失/格式错误提示；可下载模板。

## 4. 重要性与风险评估

1. 「风险评估」分区 → 设定基准（税前利润/收入/资产）与比率。
2. 系统计算整体重要性、执行重要性、明显微小错报临界值。
3. 查看科目表、勾稽检查与风险提示。

## 5. 底稿与归档包

1. 底稿生成后可在台账点击预览/下载。
2. 「打包下载全部底稿（ZIP）」→ 包含 README、清单、校验值（SHA256）。
3. 「校验底稿包（ZIP）」上传可核对完整性；失败会告警并生成复核审批。

## 6. 报告与审批

1. 报告历史版本支持按状态筛选（草稿/复核中/已复核/已定稿）。
2. 提交复核 → 项目经理在「审批状态」或「我的待办」通过/驳回。
3. 通过报告复核后版本自动标记「已复核」并记录复核人。

## 7. 管理员日常

- **用户管理**：新增/停用账号，分配角色。
- **系统状态**：查看服务/项目/用户/磁盘、系统操作统计。
- **备份**：立即备份、校验、清理、恢复演练；恢复前自动安全备份。
- **后台任务**：超期扫描、报告推送、自动备份状态与手动执行。
- **运维报告**：导出 MD/PDF、Webhook 推送。
- **设置**：超期扫描、备份策略、报告推送时间与重试次数。

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 导入 Excel 报错 | 确认列名/格式；用模板重新整理 |
| 审批按钮不可用 | 确认当前账号是否为指派审批人 |
| 报告 PDF 中文乱码 | 使用工作台内置导出；勿用第三方转换 |
| 客户端插件未加载 | 运行桌面端内置 install-plugins；重启客户端 |
| 备份恢复前提示校验失败 | 选择其他备份或联系管理员 |

## 9. 培训检查

- [ ] 能独立完成建项、导入、生成底稿
- [ ] 能提交审批并处理待办
- [ ] 能导出底稿台账、归档包并校验
- [ ] 管理员能完成备份、恢复演练与运维报告导出
