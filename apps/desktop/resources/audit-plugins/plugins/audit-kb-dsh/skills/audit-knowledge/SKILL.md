# 共享知识库检索（audit-knowledge）

事务所已有一套共享知识库（mini4pro:8030），收录审计准则、会计准则、税法与征管、职业道德与独立性、法律法规等，共 363+ 篇、约 9000 个条款切块。

## 硬性规则

1. **先检索，再回答**：凡涉及准则/法规/制度事实的问题，必须先调用 `kb_search`；不得凭记忆或通用常识直接作答。
2. **必须标注出处与锚点**：回答句尾标注 `（出处：<文档标题> › <段落>；锚点：kb-xxxx）`；能带文件号就带文件号。锚点必须是本轮检索返回的 anchor，不能自己拼。
3. **引用必须核验**：写「第 X 条」、条款依据或应用指南段落前，先调用 `kb_verify_quotes`，传入 `[{"anchor":"...","quote":"拟引用原文片段"}]`。只有 ok=true 的锚点与原文才能作为依据；**核验失败不得引用，也不得改写成概括后继续挂锚**。
4. **查不到就说查不到**：检索无命中或命中不相关时，明确回答「共享知识库中没有找到相关规定」，并建议联系知识库管理员补充；**绝不编造条文号或条款内容**。
5. **查证是用来核对的，不是用来改答案**：先按自己的理解形成初判，再去查证。查回来的条文只有三种去向：支持初判 → 保留并附依据；与争点无关 → 保留初判；**与初判明确矛盾** → 才改口，并指出矛盾在哪一句原文上。不要因为「查到一条相关条文」就推翻初判。
6. **注意版本时效**：默认只返回 approved 且未过期的版本；若用户问历史时点适用性，使用 `include_expired=true` 并在回答中注明版本/生效日期。检索结果含 `validity`（现行有效/已过期/已被替代）字段，引用前先看它。
7. **区分知识库与项目数据**：知识库是「通用准则/法规」；具体客户金额、科目、底稿请用项目数据工具（audit-data），不要用知识库回答具体数字。
8. **不生成审计结论**：只做检索与引用整理；审计意见只能「初拟」，并注明依据、限制与待确认事项。

## 使用方式

- `kb_search(q, top_k=5, codes=?)`：核心实体检索；返回 `anchor`（本段稳定锚点）、`article_no_cn`（能识别时）、`validity`（时效状态）、`heading_path`、`sha256`；锚点与原文用于后续核验。`codes` 可限定分类：
  - K-01 审计准则、K-02 会计准则、K-03 税法、K-05 职业道德、K-07 底稿模板、K-12 法规
- 命中结果含 `ref`（出处）、`text`（原文）、`doc`（分类/标题/文件号/生效日期）。
- 需要核对上下文时用 `kb_get_doc(doc=<ref 前半段>)` 取整篇切块（切块同样带 anchor）。
- `kb_verify_quotes(quotes='[{"anchor":"kb-...","quote":"..."}]')`：逐条核验锚点是否存在、片段是否为原文子串；返回每项 ok 与 reason。
- 确认某准则是否在库用 `kb_list_docs(code=)`。

## 回答格式建议

先给结论（1~2 句），再列依据（出处），最后列「待确认事项」。不要整段照抄原文，用业务语言讲清条件与数字。

示例：

> 存货期末应按成本与可变现净值孰低计量；可变现净值低于成本的，计提存货跌价准备并计入当期损益。
> 出处：《企业会计准则第1号——存货》› 正文 第3段。
> 待确认：该公司存货是否已按单项/类别测试可变现净值。
