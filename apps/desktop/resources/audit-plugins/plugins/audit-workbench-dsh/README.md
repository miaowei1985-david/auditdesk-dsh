# @local/dsh-audit-workbench

审计工作台 UI 插件（原型）：

- 左侧栏新增两个全局面板入口：**客户与项目**、**知识库**；
- 客户与项目：公司 → 项目两级主线，项目内四个分区（资料清单 / 审计底稿 / 项目对话 / 审批状态）；
- 知识库：分类浏览、关键词检索、条文全文与出处；
- 数据源：mini4pro 共享网关 `http://100.101.170.7:8030/audit/projects` 与 `/kb/*`。

## 本机引擎集成（2026-11-23）

「客户与项目」→ 项目 → **审计底稿** 分区新增紫色按钮 **「本机引擎生成（全量勾稽）」**：

1. 读取该项目的资料清单（`/audit/pbc`），按文件名挑出科目余额表 / 财务报表 / 序时账；
2. 从网关下载附件，POST 到同源接口 `POST /api/audit-fill/run`（由 `@local/audit-excel` Host 插件提供）；
3. 本机运行 `audit-fill` 引擎，生成 4 本明细底稿 + 01 主底稿 + J 现金流量表；
4. 结果回显勾稽：`勾稽 x/y 一致；差异 N 项：科目 金额…；输出 <目录>`。

与「一键生成常用底稿（4 类）」的区别：后者由网关按报表填 4 类；本机引擎用**科目余额表+报表+凭证**，
做全量勾稽（含账龄、现金流、差异归因）。

注意：本机引擎输出在 `audit-fill/out/<客户>/<期间>/底稿包`，暂不写入网关的 generated_workpapers。

### 回传网关与附件选择（2026-11-23 第二轮）

- 审计底稿工具栏新增三个下拉框：**余额表 / 报表 / 凭证（可选）**，选项来自该项目资料清单（PBC）；
  默认「自动」按文件名启发式匹配。
- 生成完成后，本机把 6 个文件（4 本明细底稿 + 01 主底稿 + J 现金流量表）回传到网关
  `POST /audit/workpapers/upload`，因此右侧「已生成底稿」列表会直接出现这些文件，可预览/下载。
- 网关新增接口（server.py，已部署并冒烟通过）：

```
POST /audit/workpapers/upload?project=&kind=&filename=   body=文件二进制
```

回显：`本机引擎：勾稽 x/y 一致；已回传网关 N 个文件；本机输出 <目录>`。
