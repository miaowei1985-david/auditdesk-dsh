# 审计底稿填表

把客户的 Excel 资料（科目余额表、财务报表、可选凭证）按事务所模板填成审计底稿。

## 工具

| 工具 | 作用 |
|---|---|
| `audit_fill_process` | 处理一家客户，生成四本明细底稿 + 01 主底稿 + 现金流量表，返回逐项勾稽 |
| `audit_fill_companies` | 列出已配置的客户资料 |
| `audit_fill_ledger` | 导出 Excel 台账（公司汇总/勾稽明细/待取证/文件清单） |

## 支撑逻辑

底层是本机项目 `audit-fill`（Python）：

- 科目余额表解析：多币种「综合本位币」续行、老准则代码、Excel/HTML 伪装格式；
- 模板填表：只写输入格、保护公式、合并单元格安全写入、每条记录留依据；
- 勾稽：TB ↔ 报表、底稿 ↔ 报表、凭证 ↔ TB，差异分实质/列报/报表无此行；
- 账龄：按凭证 FIFO 推算。

## 限制

- 报表为 PDF、或流水式「科目汇总表」时不会硬解析，会报错或标记，避免填错；
- 单科目缺数据只记 warning，不中断整家；
- 需要本机安装 Python 3 与 openpyxl/xlrd，以及 LibreOffice（用于 .xls 兜底转换和公式重算）。
