# 审计底稿工具使用手册

面向项目组：在 DeepSeek Harness 对话里，用自然语言完成底稿填制、勾稽、备忘录与复核。

## 一、五个常用场景

### 1. 看各家进度

> 「各家到哪一步了？」

调用 `audit_workflow`，返回每家所处阶段（资料接收→底稿填制→勾稽核对→差异处理→出具备忘录→复核→归档）与下一步动作。

### 2. 填一家新客户

> 「把 XX 公司的底稿填一下：科目余额表在 …、报表在 …、凭证在 …」

调用 `audit_fill_process`。需要提供：
- `company`：客户代码（输出目录名）；
- `tb`：科目余额表路径；
- `fs`：财务报表路径；
- `voucher`：凭证/序时账（可选，有则做账龄与账证核对）；
- `base_dir`：资料根目录（默认 `/Users/macbook/Documents/审计底稿`）。

### 3. 看某家差在哪

> 「中天有差异吗？」

`audit_status` 给四类计数：一致 / 实质差异 / 列报差异 / 报表无此行。
实质差异要客户补或确认；列报差异不追；报表无此行不算差异。

### 4. 出备忘录

> 「给丸金出一份备忘录」

`audit_memo` 生成 `out/备忘录/<公司>.md`：资料来源、执行情况、未解决差异、待取证、结论（可出具 / 不宜直接出具）。

### 5. 复核归档

> 「中天复核，复核人张三」

`audit_review` 记录复核人、时间、备注，并快照当时的勾稽计数；流程进入归档阶段。

### 6. 跑自检

> 「跑一下自检」

`audit_selfcheck` 用真实客户文件校验 16 项关键解析结果，改代码后先跑它。

## 二、批量与交付

| 需求 | 工具 |
|---|---|
| 12 家全部重跑 | `audit_fill_batch` |
| 只跑某几家 | `audit_fill_batch(companies=[...])` |
| 导出 Excel 台账 | `audit_fill_ledger` |
| 看这次改了什么 | `audit_changes` |
| 列已有客户 | `audit_fill_companies` |

交付物：`out/<公司>/<公司>_底稿包.zip`（4 本明细底稿 + 01 主底稿 + J 现金流量表 + 填写清单 + 校验报告 + 公司报告）。

## 三、资料要求与常见问题

| 情况 | 处理 |
|---|---|
| 多币种余额表 | 自动取「综合本位币」续行；优先用全币种表 |
| 旧准则科目表（1131/2121/1243） | 自动识别并换算为新准则 |
| 英文科目名 | 内置英文别名（accounts receivable 等） |
| 报表是 PDF | 暂不支持，需人工录入或导 Excel |
| 流水式「科目汇总表」 | 不硬解析，请客户导出标准余额表 |
| 施工企业 | 工程施工归合同履约成本，不计入存货 |
| 缺累计折旧/摊销 | 按报表净额倒推并在备注标注 |
| 应交税费总账≠子科目 | 保留差异并标注，等客户确认 |

## 四、判断口径

- **实质差异**：能从 TB 重算但对不上，通常是客户资料问题；
- **列报差异**：同一笔在另一行，或总额/净额不同，不追；
- **报表无此行**：客户报表本身没有该行，不算差异；
- 收入与成本同时存在、差额≈成本 → 客户用净额法，属列报。
